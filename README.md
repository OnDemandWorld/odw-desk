# Desk — Built

Desk is a self-hosted, WhatsApp-first AI customer-support agent. It handles customer conversations across channels but leads with WhatsApp, which is genuinely underserved in the self-hosted/open-source world.

## Differentiator
Sovereignty angle plus deep suite integration: support conversations contain customer PII, and Desk keeps that data in your own database while answering from your own Vault knowledge base — so the agent's answers are grounded in your real, private documentation rather than a generic model.

## Target
Regulated businesses that can't send customer conversations to a cloud SaaS.

## Monetization
Free core covers self-hosted chatbot functionality and basic channels; paid layer adds WhatsApp Business connector, multi-agent routing, compliance and audit features, and SLA-backed support.

## Positioning
A module of the suite, not a standalone Chatwoot competitor.
